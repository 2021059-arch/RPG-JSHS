# 전곽: IRON FIST — THE BEST

전곽 세계관 20인의 캐릭터로 즐기는 **실시간 60fps 2D 격투 액션 & 다대다 팀 난전(최대 5 vs 5)** 웹 게임입니다.  
별도 설치나 빌드 과정 없이 `index.html`을 브라우저로 열거나 **GitHub Pages**에 배포해 바로 플레이할 수 있습니다.

## 게임 모드
- **⚔️ 1v1 대전 (VS CPU)**: 원하는 캐릭터·상대·스테이지·AI 난이도(`EASY` / `NORMAL` / `HARD`) 자유 대전
- **🔥 다대다 팀 난전 (최대 5v5)**: BLUE 팀 vs RED 팀 `1~5인` 자유 편성 난투 (`🎮 직접 참전 + Tab/Q 실시간 태그 교대` / `🍿 AI 자동 난전 관전` / `👑 1vs다수 레이드 보스 자동 보정`)
- **🏆 아케이드 5연전**: 5단계 토너먼트 래더 돌파 모드
- **👥 2인 로컬 대전**: 키보드 하나로 즐기는 1P vs 2P 대전
- **🎯 트레이닝**: 무한 체력·무한 게이지 콤보 연습 및 히트박스(`BOX`) 확인 모드

## 조작법 (슬롯 선택 + Enter 발동 시스템)
| 동작 | 키 입력 | 설명 |
| :--- | :--- | :--- |
| **앞뒤 이동 / 점프 / 숙이기** | `W A S D` 및 `방향키 (↑ ← ↓ →)` | 두 키셋 동시 지원 (`Shift` 또는 `→→`/`←←`: 스텝 대시) |
| **가드 (수비 / 저스트 가드)** | `Space` (스페이스바) | `숙이기(S/↓) + Space`: 하단 가드 / 공격 직전 방어 시 `JUST GUARD` |
| **기술 슬롯 선택 (유지됨)** | 숫자키 `1` · `2` · `3` · `4` | 다른 숫자키(`1~4`)를 누르기 전까지 해당 슬롯 선택 상태 유지 |
| **선택된 기술 발동** | `Enter` | 현재 선택된 슬롯(`1~4`) 기술만 초저쿨타임으로 연속 발동 |
| **[1번 슬롯] 속공 3연타** | `1` 선택 후 `Enter` 연타 | **쿨타임 0초** · 3단 콤보 러시 (`S/↓ + Enter`: 하단킥 / 공중 `Enter`: 점프타격) |
| **[2번 슬롯] 라이징 어퍼** | `2` 선택 후 `Enter` | **초저쿨(0.25초)** · 공중 콤보 띄우기 & 상대 가드 내구도 대폭 파쇄 |
| **[3번 슬롯] 고유 기술 1** | `3` 선택 후 `Enter` | **초저쿨(0.40초)** · 캐릭터별 시그니처 장풍 · 7색 레이저 · 과구리포 · 돌진기 |
| **[4번 슬롯] 고유 강습기 2** | `4` 선택 후 `Enter` | **초저쿨(0.55초)** · 슈퍼아머 맞딜 돌파 & 공중 바운드 강타 |
| **🔥 [5번] 초필살기 (즉시 발동)** | 숫자키 `5` 단독 입력 | **숫자키 `5`를 눌렀을 때만 즉시 발동!** (게이지 100% 또는 체력 30% 이하 `RAGE` 각성) |
| **🔄 [팀 난전] 아군 교대** | `Tab` 또는 `Q` | 생존한 아군 캐릭터로 즉시 태그 조작 전환 (상단 초상화 클릭 지원) |
