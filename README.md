# 전곽: IRON FIST — THE BEST

전곽 세계관 20인의 캐릭터로 즐기는 **실시간 60fps 2D 격투 액션 & 다대다 팀 난전(최대 5 vs 5)** 웹 게임입니다.  
별도 설치나 빌드 과정 없이 `index.html`을 브라우저로 열거나 **GitHub Pages**에 배포해 바로 플레이할 수 있습니다.

## 게임 모드
- **⚔️ 1v1 대전 (VS CPU)**: 원하는 캐릭터·상대·스테이지·AI 난이도(`EASY` / `NORMAL` / `HARD`) 자유 대전
- **🔥 다대다 팀 난전 (최대 5v5)**: BLUE 팀 vs RED 팀 `1~5인` 자유 편성 난투 (`🎮 직접 참전 + Tab 실시간 태그 교대` / `🍿 AI 자동 난전 관전` / `👑 1vs다수 레이드 보스 자동 보정`)
- **🏆 아케이드 5연전**: 5단계 토너먼트 래더 돌파 모드
- **👥 2인 로컬 대전**: 키보드 하나로 즐기는 1P vs 2P 대전
- **🎯 트레이닝**: 무한 체력·무한 게이지 콤보 연습 및 히트박스(`BOX`) 확인 모드

## 조작법 (1P 기준)
| 동작 | 키 입력 |
| :--- | :--- |
| **이동 / 점프 / 앉기** | `W A S D` 또는 `방향키` (뒤로 당기면 자동 가드, `Space` 수동 가드) |
| **스텝 대시 / 백대시** | `Shift` 또는 `→→` / `←←` |
| **3단 러시 (기본 연속기)** | `J - J - J` (또는 `Z - Z - Z`) |
| **하단 스윕 킥** | `↓ + J` (또는 `↓ + Z`) |
| **중단 강타 / 어퍼컷 띄우기** | `K` / `↓ + K` (또는 `X` / `↓ + X`) |
| **잡기 / 잡기 풀기** | `L` (또는 `G`) |
| **고유 필살기 1** | `U` (또는 `C`) |
| **파워 크러시 강습기 (슈퍼아머)** | `I` (또는 `V`) — HEAT 25% 소모 |
| **🔥 레이지 아츠 (초필살기)** | `O` (또는 `B`) — 체력 35% 이하 `RAGE` 또는 `HEAT 100%` |
| **🔄 [팀 난전] 아군 실시간 교대** | `Tab` 또는 숫자키 `1 ~ 5` (상단 아군 초상화 클릭 지원) |
