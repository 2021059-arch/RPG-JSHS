# 전곽: IRON FIST — THE BEST (v3)

전곽 세계관 20인의 캐릭터로 즐기는 **실시간 60fps 2D 격투 액션 & 다대다 팀 난전(최대 5 vs 5)** 웹 게임입니다.  
별도 설치나 빌드 과정 없이 `index.html`을 브라우저로 열거나 **GitHub Pages**에 배포해 바로 플레이할 수 있습니다.

## v3 주요 변경점
- **타이틀 화면 & 메인 메뉴**: 게임 시작 · 조작 가이드 · 전적 기록 · 설정 (키보드 ↑↓ + Enter 지원)
- **VS 스플래시 연출**: 대전 직전 양 진영 초상화 슬라이드 인 + 스테이지 소개 (Enter/Space로 스킵)
- **게이지 시스템 확장 (`5`번 키 상황별 발동)**: 초필살기 · 💥 콤보 브레이커 · 🛡️ 가드 캔슬
- **COUNTER / PUNISH 판정**, 진짜 콤보(True Combo) 카운트 & 콤보 종료 평가(GOOD → LEGENDARY)
- **CPU AI 강화**: 대공(점프 격추) · 헛친 기술 응징 · 점프 오버헤드 · 브레이커/가드캔슬 사용
- **트레이닝 모드 데이터 패널**: 발생/지속/후딜 프레임, 가드·히트 이득(+/−), 입력 기록, 더미 행동(가만히/전부 가드/랜덤 가드/브레이커)
- **이펙트 엔진 전면 개선**: 무기 궤적, 만화식 집중선, 임팩트 프레임, 카메라 줌 펀치, 저체력 맥동 비네트, RAGE 불씨 오라, 투사체 궤적, 착지·대시 잔상
- **사운드 엔진**: 마스터/효과음/배경음악 개별 볼륨, 리미터, 신규 효과음 20여 종, 타이틀 BGM
- **결과 화면**: S/A/B/C/D 퍼포먼스 등급 + 상세 전투 통계, 팀 난전 딜량 랭킹 그래프
- **설정 & 전적 저장** (`localStorage`): 화면 흔들림 · 섬광 · 데미지 숫자 · 그래픽 품질 · 아나운서 음성 / 승률 · 연승 · 최대 콤보 · 애용 캐릭터
- **버그 수정**: 대시가 끝나지 않고 굳어 버리던 문제(CPU가 멈춰 있던 원인) 해결

## 게임 모드
- **⚔️ 1v1 대전 (VS CPU)**: 원하는 캐릭터·상대·스테이지·AI 난이도(`EASY` / `NORMAL` / `HARD`) 자유 대전
- **🔥 다대다 팀 난전 (최대 5v5)**: BLUE 팀 vs RED 팀 `1~5인` 자유 편성 (`🎮 직접 참전 + Tab/Q 교대` / `🍿 AI 관전` / `👑 1 vs 다수 레이드 보정`)
- **🏆 아케이드 5연전**: 5단계 토너먼트 래더 돌파 모드
- **👥 2인 로컬 대전**: 키보드 하나로 즐기는 1P vs 2P 대전
- **🎯 트레이닝**: 무한 체력·게이지, 프레임 데이터, 히트박스(`BOX`) 확인

## 조작법
| 동작 | 키 입력 | 설명 |
| :--- | :--- | :--- |
| **이동 / 점프 / 숙이기** | `W A S D` 및 `방향키` | 두 키셋 동시 지원 (`Shift` 또는 `→→`/`←←`: 스텝 대시) |
| **가드** | `Space` | `↓ + Space`: 하단 가드 / 피격 직전 입력 시 `JUST GUARD` (게이지 +20) |
| **기술 슬롯 선택 (유지)** | `1` · `2` · `3` · `4` | 다른 숫자키를 누르기 전까지 선택 유지 |
| **선택 기술 발동** | `Enter` | 쿨타임 `0` / `0.25` / `0.40` / `0.55`초 |
| **[1] 속공 3연타** | `1` → `Enter` 연타 | `↓ + Enter` 하단 스윕 / 공중 `Enter` 오버헤드 / 대시 중 `Enter` 대시 강습 |
| **[2] 라이징 어퍼** | `2` → `Enter` | 띄우기 & 가드 파쇄, 슈퍼아머 파훼 |
| **[3] 고유 기술** | `3` → `Enter` | 장풍 · 7색 레이저 · 과구리포 · 돌진기 |
| **[4] 고유 강습기** | `4` → `Enter` | 슈퍼아머 돌파 & 바운드 강타 |
| **🔥 게이지 키** | `5` | 평상시: **초필살기** (100% 또는 체력 30% 이하 RAGE 1회) |
| **💥 콤보 브레이커** | 맞는 중 `5` | 게이지 50% · 콤보 탈출 & 주변 적 밀쳐내기 (재사용 대기 2.4초) |
| **🛡️ 가드 캔슬** | 막는 중 `5` | 게이지 50% · 무적 반격 |
| **🔄 아군 교대 (팀 난전)** | `Tab` / `Q` | 생존 아군으로 즉시 조작 전환 |
| **일시정지 / 커맨드 리스트** | `Esc` | 현재 캐릭터의 기술 프레임 · 데미지 · 쿨타임 표시 |

### 캐릭터 선택 화면
`←↑↓→` 캐릭터 이동 · `Space` 선택 · `Tab` 1P/2P(팀) 전환 · `R` 랜덤 · `Enter` 대전 시작 · `Esc` 타이틀
